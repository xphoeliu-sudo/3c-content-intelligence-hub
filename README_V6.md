# 3C Wearables Competitive Intelligence V6

Four modules:
1. Market & Product: Apple/Samsung/Garmin global new products, technology updates, launch events, marketing actions.
2. PDP / PCP Monitor: Apple/Samsung/Garmin, Global/China/Malaysia/UK. Captures screenshots, structure, commerce links, video signals and changes.
3. Amazon Watch: wearables first, plus high-interest new/trending tech and Apple on Amazon.
4. Social Content Watch: Global + Malaysia, Apple/Samsung/Garmin. YouTube is collected directly; Instagram/TikTok are discovery signals when publicly indexed.

Required GitHub secret: DASHSCOPE_API_KEY.
Model: qwen3.5-plus through DashScope compatible endpoint.

Do not delete data.json if you want to preserve previous snapshots. V6 can start with an empty/new data.json.

Run:
Actions → V6 Update Intelligence → Run workflow.
Then:
Actions → Deploy V6 Dashboard → Run workflow.

GitHub Pages should use GitHub Actions as the publishing source.
